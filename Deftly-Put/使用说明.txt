Deftly Put · X 跨文化交流助手
macOS / Google Chrome 自用版

首次安装

1. 把整个 Deftly-Put 文件夹留在一个固定位置。如果拿到的是 ZIP，请先解压。
2. 双击「安装本机助手.command」。首次安装或更新本机助手时都要运行这一步。助手使用这台 Mac 的 /usr/bin/python3 和 /usr/bin/openssl。
3. 在桌面版 Google Chrome 地址栏输入 chrome://extensions，开启右上角「开发者模式」，点击「加载已解压的扩展程序」，选择包里的 extension 子文件夹。选中这一层时能看到 manifest.json。
4. 点击 Chrome 工具栏的拼图图标，打开「Deftly Put」。点击「Continue with ChatGPT」，在 OpenAI 页面选自己的账号和工作区，允许此工具使用 ChatGPT 套餐。看到「已连接 ChatGPT」后回到 X。已经打开的 X 页面请刷新一次。

设置语言和发帖

打开 Chrome 工具栏的「Deftly Put」，在「翻译设置」选择默认源语言和默认目标语言，点击「保存语言设置」。源语言用于理解草稿和显示回译。首次安装时取 Chrome 的界面语言，旧版首次升级到带此设置的版本时取升级当时的界面语言。之后更改 Chrome 的语言不会覆盖已保存的选择。默认目标语言初始为英语。

在 X 上自己发帖时，写好草稿后点击「翻译」，插件会使用默认目标语言。要为这一条帖子换语言，展开翻译按钮旁的三角形，手动选择目标语言即可。

用对方的语言回复

在 X 网页版点某条帖子的「回复」，用中文或自己熟悉的语言写好草稿，再点底栏的「翻译」。默认跟随被回复帖子的语言，使用自然口语。如果 X 显示「翻译自 英语」，即使屏幕上是中文，回复也会译成英语。点击翻译按钮旁的三角形，可展开目标语言和语气。选中的按钮会加粗，再点三角形可收起。手动选择的语言优先。如果 X 的翻译标记没有给出可识别的原文语言，插件会提示你手动选择。

草稿可以是一句完整的回复，也可以是你想表达的意思。写「请把链接发给我」，得到的是向对方要链接的回复。写「夸他一下」，得到的是结合帖子内容、直接对作者说的一句赞美。零散的想法会整理成自然的回复，例如「问问他需要哪方面的帮助，我也许能帮忙」会保留「也许」的语气。这几种写法都用同一个按钮。

生成回复前，Deftly Put 会检查措辞在这段对话和场合里是否可能引起明显冒犯。如果对方已经说明了习俗、偏好或边界，它会在能保留你原意的地方调整表达。线索不足时，它会用自然、得体的说法，避免凭姓名或语言推断个人信仰。你明确要传达的事实、提醒和立场仍会体现在回复中。

如果对方也是在回复别人，插件会参考可读取的上游对话，从你正在回复的帖子向上最多取最近 3 层，按发言顺序排列，每条最多 1,000 个字符。直接引用的帖子会作为单独的背景材料。当前页面缺少上文时，插件会参考同一窗口已打开的对应详情页，必要时直接在后台向 X 读取公开帖子。读取失败时，使用已经取得的内容继续生成回复。目标语言仍跟随直接回复对象，或采用你的手动选择。

译文会填回 X 草稿。插件会将实际生成的译文单独交给 OpenAI，译回本次翻译使用的源语言。「回译」在输入框下方单独显示，供你核对意思。X 发送时只读取编辑框。手动微调译文后，停下输入片刻，下方会自动回译修改后的文字。清空回复框、大幅改写，或改回本轮草稿所用的语言重新起草时，回译会收起。插件在本机结合本轮草稿语言、译文语言和实际修改的文字判断；只换一个外语词通常仍按微调处理。改写中文后，点「翻译」会按当前草稿重新生成译文。如果 X 编辑器未能写入，面板会单独显示可复制的译文及其回译。你可以继续改字，或在尚未手改时点「撤销翻译」还原原文。发送由你在 X 中确认。翻译过程中如果继续编辑草稿，插件会保留你的编辑，并把可复制的译文显示在下方。

同一标签页刷新或切换回复对象时，如果 X 将上一条回复的译文带进了另一帖，插件会移除识别出的旧译文。想沿用这段话，可以点「恢复上条回复的译文」。

账号、用量和数据

OpenAI 在云端生成译文，使用所选 ChatGPT 账户允许共享的套餐额度。模型从该账户开放给这个客户端的模型列表中选取。生成回复时会向 OpenAI 发送草稿、被回复帖子、可确认的上游对话与引用帖（含作者标识和节选），以及翻译设置。回译是独立请求，只发送要核对的当前译文和本次翻译使用的源语言。扩展在当前浏览器会话中按标签页暂存最近一次写入译文的指纹、长度和原帖标识，用于识别串帖。记录不含译文正文，关闭标签页后清除。

Chrome 通过原生消息连接本机助手。OAuth 登录只在授权期间使用 127.0.0.1 上的临时回调端口。助手把凭据保存在 ~/Library/Application Support/XReplyTranslator/account/ 下的仅限当前 macOS 用户读取的文件中。不要分享这个目录。退出可在扩展菜单操作，也可在 ChatGPT 的应用连接设置中撤销授权。

排查

• 找不到助手：重新运行「安装本机助手.command」，并在 chrome://extensions 中检查扩展 ID 是否为 hbddhnfhdjncdbolcapilkemcaccnoai。
• 找不到按钮：确认正在桌面版 x.com 的发帖框或回复框中写草稿，刷新页面再打开编辑框。
• 原帖语言不明确：点击翻译按钮旁的三角形，手动选目标语言。
• 额度或授权错误：在扩展菜单重新连接正确的账号或工作区，并在 ChatGPT 设置里检查套餐授权与可用额度。
• 更新：在原来的目录替换扩展文件后，打开 Chrome 工具栏的「Deftly Put」，插件会读取新版本。再次打开时，标题显示当前运行的版本。如果 X 页面仍显示旧控件，请先保存草稿，再刷新该页。只有本机助手也有更新时，才需要重新运行安装命令。
